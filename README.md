MVP — Projeto
Sobre o projeto
Este projeto é um MVP (Minimum Viable Product) desenvolvido com o objetivo de validar uma solução de forma simples, funcional e organizada.

A aplicação foi construída considerando boas práticas de desenvolvimento de software, organização do código, controle de versão e facilidade de manutenção.

Funcionalidades
Cadastro e gerenciamento das principais informações da aplicação.

Validação dos dados inseridos pelo usuário.

Interface para interação com as funcionalidades do MVP.

Tratamento de erros e informações inválidas.

Organização do código visando facilitar futuras evoluções.
